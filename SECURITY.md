# Security

Please do not publish API keys, private chat text, phone numbers, screenshots containing personal information, or account credentials in an issue.

If you find a vulnerability that could expose private data or credentials, report it privately through GitHub's security-advisory feature when available. Include the affected version, reproduction steps, and likely impact.

WA Canvas never needs your WhatsApp password, verification code, or encryption keys. Do not trust a modified build that asks for them.
