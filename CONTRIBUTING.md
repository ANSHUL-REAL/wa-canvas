# Contributing to WA Canvas

Thanks for helping make WA Canvas better. You do not need to be an expert—clear bug reports, simpler wording, translations, theme ideas, and accessibility feedback are valuable too.

## Before you start

1. Search existing issues before opening a new one.
2. Keep features optional and controlled by the user.
3. Do not add analytics, trackers, remote scripts, message automation, contact scraping, spam tools, or security bypasses.
4. Do not collect chat content silently. Any AI feature must clearly show what will be sent and require an intentional user action.
5. Use plain language in settings so non-technical users understand what a control does.

## Local development

1. Fork and clone the repository.
2. Load the folder through `chrome://extensions` using **Load unpacked**.
3. Reload the extension and refresh WhatsApp Web after changing files.
4. Test Light, Dark, and at least one colorful theme.
5. Check the browser console for errors.

## Pull requests

Explain what changed, why it helps, how you tested it, and whether it affects privacy or permissions. Small, focused pull requests are easiest to review.

Be kind. Assume good intent, explain decisions clearly, and help newcomers feel welcome.
