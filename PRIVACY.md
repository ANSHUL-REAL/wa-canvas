# Privacy Policy

WA Canvas is designed to keep customization data on your device.

## Data stored locally

The extension may store theme choices, display settings, keyboard shortcuts, privacy-control preferences, local wallpaper data, and an optional Groq API key in Chrome extension storage.

## Network requests

Normal visual customization does not require a WA Canvas server. If you choose to use Groq AI, the text you manually place in the AI box is sent directly to Groq together with your API key. WA Canvas does not automatically collect or transmit full conversations.

## Analytics and advertising

WA Canvas contains no analytics, advertising, tracking pixels, or sale of personal data.

## Removing data

Use **Reset defaults** to remove regular settings and wallpaper data. Use **Remove** beside the Groq key to delete that key. Removing the extension also removes its Chrome-managed local storage.

Because this is open-source software installed by the user, anyone can inspect the source and verify how data is handled.
